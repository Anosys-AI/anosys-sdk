# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email [support@anosys.ai](mailto:support@anosys.ai) with "Security" in the subject, and include:

- the package and version affected;
- what an attacker could do, and how to reproduce it;
- any logs or proof of concept, with secrets removed.

We will confirm that we received your report and keep you updated until the issue is fixed. Please give us a reasonable time to release a fix before disclosing it publicly.

## Supported versions

Security fixes go into the latest release of each package. Upgrade to the newest version to receive them; see the [release notes](RELEASE_NOTES.md).

## How the SDKs handle your data

What each integration sends, the collection levels and client-side encryption are described in [PRIVACY.md](PRIVACY.md) and [DATA_CONTROLS.md](DATA_CONTROLS.md).
