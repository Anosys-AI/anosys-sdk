# AnoSys Telemetry Variables Map

This document provides the complete reference for all telemetry variables used across the AnoSys SDK, including **Named Variables** (used in JSON payloads and API ingestion) and **CV Variables** (**C**ustom **V**ariables — physical database columns `cvs*`, `cvn*`, `cvb*` used for indexed storage, BigQuery, dashboard widgets, and platform algorithms).

---

## 1. Architecture: Dual Schema Representation

Every event processed by the AnoSys SDK hook runner is emitted with two parallel representations:

1. **Named Variables (JSON Payload)**: Human-readable, descriptive keys (e.g. `session_id`, `input_tokens`, `cost_estimate`, `user_prompt`). This format is used by ingestion endpoints, REST APIs, logging sinks, and developer integrations.
2. **CV Variables (Physical Database Columns)**: Optimized, indexed columnar fields (`cvs1`–`cvs200` for strings, `cvn1`–`cvn100` for numbers, `cvb1`–`cvb100` for booleans). These columns map directly to the underlying BigQuery / ClickHouse tables, powering dashboard graphs, real-time metrics, anomaly detection, and automated triggers without schema alteration.

## 2. Named Variables Reference

This table describes every named variable generated by the hook runner and mapper, including its type, mapped CV column, and purpose.

| Variable Name | Data Type | Mapped CV Column | Category | Description |
| :--- | :--- | :--- | :--- | :--- |
| `session_id` / `sessionId` | `string` | `cvs1` | Session Identity | Unique identifier for the agent session or conversation thread (e.g., `thread-id` or UUID). All turns in the same CLI conversation share this ID. |
| `uuid` / `event_id` / `eventId` | `string` | `cvs13` / `event_id` | Event Identity | Unique identifier for the individual turn or event. In Codex, this corresponds to the `turn_id`. |
| `event_type` | `string` | System Field | Event Lifecycle | Lifecycle event category classification (e.g. `agent-turn-complete`, `turn-complete`, `test`). |
| `event_source_name` | `string` | System Field | Source Identity | The originating harness or application identifier (e.g. `codex`, `claude_code`). |
| `timestamp` | `number` / `string` | System Field | Timing | Ingestion / event timestamp (ISO 8601 UTC string or epoch milliseconds). |
| `user_timestamp` | `number` / `string` | System Field | Timing | Timestamp recorded on the client machine when the turn actually completed. |
| `debug` | `boolean` | `cvb1` | Operational | Boolean flag indicating whether the CLI session was running with debug logging enabled. |
| `user_prompt` / `userPrompt` | `string` | `cvs4` | Content | Text of the prompt or instruction provided by the user. If `--redact` is enabled, this is masked. |
| `assistant_text` / `assistantText` | `string` | `cvs5` | Content | Text response generated by the assistant during this turn. If `--redact` is enabled, this is masked. |
| `model` / `primary_model` | `string` | `cvs9` | Model | Name of the primary AI model used for the turn (e.g. `o3`, `gpt-4o`, `codex-1`). |
| `model_provider` | `string` | `cvs17` | Model | The AI infrastructure provider supplying the model (e.g. `openai`, `anthropic`). |
| `cwd` | `string` | `cvs12` | Environment | Absolute path of the working directory on the host machine where the session ran. |
| `project` | `string` | `cvs2` | Environment | Project name, extracted as the basename of `cwd` (e.g. `my-app`). |
| `permission_mode` / `permissionMode` | `string` | `cvs7` | Security | Codex approval policy active during the turn (e.g. `ask_all`, `auto`, `ask`). |
| `sandbox_mode` | `string` | System Field | Security | Codex sandbox execution policy (e.g. `read_write`, `read_only`, `dangerously_disable`). |
| `duration_ms` | `number` | `cvn6` | Performance | Total elapsed duration of the turn in milliseconds from start to completion. |
| `input_tokens` | `number` | `cvn1` | Token Usage | Number of prompt / input tokens processed by the model for this turn. |
| `output_tokens` | `number` | `cvn2` | Token Usage | Number of completion / output tokens generated by the model for this turn. |
| `total_tokens` | `number` | `cvn3` | Token Usage | Total cumulative tokens for the turn (`input_tokens + output_tokens + cache_read`). |
| `cache_read` | `number` | `cvn4` | Token Usage | Number of prompt tokens retrieved directly from OpenAI's prompt cache. |
| `cache_creation` | `number` | `cvn5` | Token Usage | Number of tokens written into the prompt cache for subsequent turn reuse. |
| `reasoning_tokens` | `number` | System Field | Token Usage | Number of internal reasoning / "thinking" tokens generated by reasoning models (e.g. `o1`, `o3`). |
| `cost_estimate` | `number` | `cvn7` | Financial | Estimated financial cost in USD for this turn, computed using exact model token pricing tiers. |
| `incremental_input` | `number` | `cvn9` | Deltas | Marginal input tokens consumed specifically in this turn (excluding session carry-over). |
| `incremental_output` | `number` | `cvn10` | Deltas | Marginal output tokens generated specifically in this turn. |
| `incremental_total` | `number` | `cvn11` | Deltas | Marginal total tokens consumed specifically in this turn. |
| `incremental_cost` | `number` | `cvn12` | Deltas | Marginal estimated cost in USD incurred specifically in this turn. |
| `incremental_cache_read` | `number` | `cvn17` | Deltas | Marginal cache read tokens specifically in this turn. |
| `incremental_cache_creation` | `number` | `cvn18` | Deltas | Marginal cache creation tokens specifically in this turn. |
| `tool_count` | `number` | `cvn41` | Tool Execution | Total number of tool invocations (commands, file operations, web searches) executed in this turn. |
| `tool_duration_ms` | `number` | `cvn39` | Tool Execution | Total cumulative time in milliseconds spent waiting for tool and command executions to complete. |
| `tools_used` | `array` | System Field | Tool Execution | Array of unique tool names invoked during the turn (e.g. `["exec", "apply_patch", "web_search"]`). |
| `commands` | `array` | `cvs90` | Tool Execution | List of shell / terminal commands executed by the agent during this turn. |
| `written_paths` | `array` | `cvs91` | File System | List of file paths modified, created, or patched by the agent during this turn. |
| `has_thinking` | `boolean` | `cvb2` | Model | Boolean flag: `true` if the model utilized reasoning / thinking tokens during execution. |
| `integration_version` | `string` | `cvs32` | Metadata | Version string of the installed AnoSys SDK integration package (e.g. `0.1.0`). |
| `os_user` | `string` | `cvs33` | Environment | Operating system username of the user running the CLI tool. |
| `raw` / `cvs199` | `string` | `cvs199` | Audit Context | Complete serialized JSON string of all raw rollout events, tool outputs, and metadata. |
| `source_tag` / `cvs200` | `string` | `cvs200` | Source Tag | Source hook signature tag (`CodexHook` for Codex, `ClaudeCodeHook` for Claude Code, `AntigravityHook` for Google Antigravity). |

## 4. Codex vs Claude Code Parity Alignment

Because Codex and Claude Code both use the **`CC`** pixel format, their metrics align identically in the AnoSys Console:

| Metric / Dimension | Codex Hook Slot | Claude Code Hook Slot | Dashboard Interpretation |
| :--- | :--- | :--- | :--- |
| **Session Tracking** | `cvs1` (`session_id`) | `cvs1` (`session_id`) | Aggregates turns into end-to-end sessions |
| **Repository** | `cvs2` (`project`) | `cvs2` (`project`) | Groups telemetry by codebase / project |
| **Model** | `cvs9` (`primary_model`) | `cvs9` (`primary_model`) | Tracks token & cost usage per model |
| **Input Tokens** | `cvn1` (`input_tokens`) | `cvn1` (`input_tokens`) | Evaluates prompt size & context window |
| **Output Tokens** | `cvn2` (`output_tokens`) | `cvn2` (`output_tokens`) | Evaluates model code generation volume |
| **Total Tokens** | `cvn3` (`total_tokens`) | `cvn3` (`total_tokens`) | Primary consumption billing metric |
| **Prompt Caching** | `cvn4` (`cache_read`) | `cvn4` (`cache_read`) | Quantifies prompt cache savings |
| **Turn Latency** | `cvn6` (`duration_ms`) | `cvn6` (`duration_ms`) | Measures turn responsiveness in ms |
| **Estimated Cost** | `cvn7` (`cost_estimate`)| `cvn7` (`cost_estimate`)| USD expenditure tracking |
| **Tool Calls** | `cvn41` (`tool_count`) | `cvn41` (`tool_count`) | Evaluates agentic action frequency |
| **Full Audit Trail** | `cvs199` (`raw`) | `cvs199` (`raw`) | In-depth inspector for tools & arguments |
| **Harness Signature**| `cvs200 = 'CodexHook'` | `cvs200 = 'ClaudeCodeHook'` | Discriminates CLI source in queries |
